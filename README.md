# 《师傅的快递为什么这么多？》

> 一款顶着"快递"招牌、内核却是 **Roguelike 卡牌塔楼远征**的独立游戏 Demo。
> 你扮演一位被快递单淹没的少年武者——不同的是，每一单"配送"都可能要你爬上一座镇守森严的塔，跟忍者、剑客、武士乃至段末 Boss 打上一架。

---

## 这游戏是什么

一句话：**杀戮尖塔式的卡牌爬塔 Roguelike，外挂一套"城镇经营 + 塔楼远征"的长线循环。**

- **局内**：每次进塔，一张随机生成的爬塔地图，靠"胜利选卡、删牌、卖卡、事件抉择"养出一套**本局独有的牌组**；
- **局外**：在城镇里囤遗物、接铁匠任务，带 5 件宝贝进塔，撤出来就永久带回家，死在塔里则血本无归——只有击败段末 Boss，才能永久解锁更深的塔。

打完一局不是结束，而是"下一局玩点什么不同"的开始。

---

## 核心循环

```
【城镇】整理仓库 · 接铁匠任务 · 选塔出发
   ↓ 带上 5 件遗物（1 轮回 + 4 普通）
【进塔】一张全新地图，从你解锁的塔段起点开爬
   · 战斗胜利 → 3 选 1 掉卡，牌组越养越成型
   · 事件 → 三选一抉择，代价与收益自己掂量
   · 商店 → 买遗物、卖卡换钱
   · 篝火 → 回血 / 删牌 / 见好就收撤离
   · 段末镇守 Boss → 击败 = 存档，解锁下一塔
   ↓ 撤离（遗物安全带回）或 死亡（全部遗失）
【回城镇】结算任务 · 遗物入仓 · 带着新解锁再进塔
```

---

## 一局之内 · 武者试炼

**随机爬塔地图**
每条路都不一样：怪物、精英、商店、随机事件、宝箱、篝火、Boss 层层排布。选哪条路、打不打精英、赌不赌事件，都是你的选择。

**卡牌回合战斗**
费用、护甲、多段伤害、流血、易伤……攻击有攻修、命中飘字、镜头抖动，胜负分明，反馈扎实。

**牌组构筑成长（本局核心乐趣）**
- 战斗胜利后从随机 3 张卡里选 1 张加入牌组；
- 篝火休息时可以在"回血 / 删一张牌 / 撤离"之间取舍——删牌是让牌组"减脂成型"的关键；
- 商店里能把手牌卖成金币，也能买到改变打法的遗物；
- 遇到稀有的**核心卡**，整局都可以围着它组套路。

每局的牌组"长法"都不一样——这就是反复开塔的理由。

**风险与抉择**
"见好就收，把遗物带回家"还是"继续深入，赌一把更大的掉落"？事件给的收益往往贴着代价，塔越深，一次失误越致命。

---

## 塔外经营 · 城镇

- **仓库与携带**：遗物永久存放在城镇仓库，进塔最多带 5 件（1 个轮回遗物槽 + 4 个普通槽），槽满后塔内新拾取需要"替换 or 放弃"；
- **撤离 / 死亡**：撤出 = 5 件安全入库；死亡 = 全部遗失，只有轮回遗物可以通过铁匠的"赎回任务"找回；
- **铁匠任务板**：接"送达 / 讨伐"任务进塔完成，回城结算换取随机遗物，档位随你征服过的塔解锁；
- **Boss = 存档点**：击败段末镇守 Boss 会永久记录在档，进塔门解锁更深的塔起点——难度随之爬升，死亡不会让你倒退；
- **单角色聚焦**：只扮演一位"少年勇士"，全部成长围绕一套专属卡池设计，构筑深度做足。

---

## 为什么值得再开一局

- **局内**：每次进塔 = 一次独一无二的牌组构筑实验，"这把没玩到的组合"就是下一把的动力；
- **局外**：遗物越囤越厚、任务越解越高级、塔越爬越深，进度永远看得见；
- **难度**：从第一塔到更高的塔，同样的敌人攻防数值逐段拔升，考验你的构筑而不是运气。

---

## 开发状态

目前为**开发中的可玩 Demo**，核心手感（地图爬塔、选路进战斗、卡牌战斗反馈）已经搭好并持续迭代。上文描述的"选卡 / 删牌 / 卖卡 / 事件抉择 / 城镇经营 / 多层塔楼 Boss 解锁"等系统正处于按里程碑逐步落地的阶段（短期先做"单局牌组养成"，再拉长塔层与经营内容）。

> 试玩反馈重点：一局时长、构筑成型感、"是否还想再开一局"——这些决定我们下一刀切什么。
